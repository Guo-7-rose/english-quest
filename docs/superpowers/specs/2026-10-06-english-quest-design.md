# 英语闯关岛（English Quest）设计文档

> 状态：待用户评审 · 日期：2026-10-06
> 原型（已交付验证）：`prototype.html`

## 1. 项目概述

一个**游戏化英语学习网站**，风格参考「打字鸭 + Qwerty Learner + Monkeytype + Duolingo」：

- 核心玩法：看中文释义/音标 → **盲打英文单词**（打字与背单词合一）
- 内容体系：「基础 → 进阶 → 高手 → 大师」四阶段闯关路线，覆盖词汇 + 语法
- 驱动引擎：每日打卡、连续天数、经验等级、连击特效、成就徽章——学习像玩游戏一样有正反馈

**目标用户**：开发者本人（单用户）。
**运行方式**：纯前端静态站，数据全部存浏览器 localStorage；构建产物为**单个 index.html**，双击即开，无需服务器；将来可零改动部署到 GitHub Pages / Netlify。

## 2. 调研结论摘要

### 2.1 网站实地调研（Chrome 浏览器访问）

| 站点 | 借鉴点 |
|---|---|
| 打字鸭 daziya.com | 闯关模式（关卡按顺序解锁）、默写训练（显示释义+音标，盲打单词）、实时 WPM/正确率、词库按教材/考试阶段组织 |
| Qwerty Learner qwerty.liumingye.cn | 逐字母着色渲染、默写模式/释义显示开关、错题本、数据统计、纯键盘操作、词典切换（CET-4 等） |
| Monkeytype | 极简打字手感、点击或按任意键聚焦、进度点阵、流畅动效 |
| Duolingo | 经验/等级/连胜、吉祥物提醒、闯关地图、卡通视觉语言 |

### 2.2 GitHub 调研（已完成，40+ 仓库核实，详见 `english-typing-gamification-research.md`）

- **Qwerty Learner**（23.3k ⭐）：**GPL-3.0**。设计思路可借鉴（跟打→默写→听写三阶递进、错误重打、错词本）；**词表数据不可直接复制**（GPL 传染）。
- **ECDICT**（8.4k ⭐）：**MIT**。自带考试分级 tag（zk/gk/cet4/cet6/ky/toefl/ielts）+ 词频（bnc/frq）+ 词形变化（exchange：复数/过去式/三单），是本项目词库的**首选数据源**。
- **ts-fsrs**（MIT）：FSRS 间隔复习调度器的 TS 实现，Anki 社区事实标准——**复习调度直接集成它，不自造算法**。
- **Harper**（16.2k ⭐，Apache-2.0，WASM 可纯前端运行）：离线语法检查器，列为未来「句子填空/改错」模式的判分引擎；v1 语法为选择题，暂不引入。
- **KyleBing/english-vocabulary**（BSD-3）：四六级/考研/SAT 词表 txt+json，作四级词表的备选交叉校验源。
- **keybr.com**（AGPL，思路参考）：按键级统计与「达标解锁新字母」；列为未来打字教学增强。
- 许可纪律：代码级复用只选 MIT/Apache/BSD（ECDICT、ts-fsrs、write-good、textlint、KyleBing 词表）；GPL/AGPL 项目仅作机制参考。
- 赛道缺口：GitHub 无成规模 awesome-typing 列表；TypeLit/10fastfingers/TypingClub 均无开源实现。

### 2.3 词库数据流水线（已核实可行）

1. 下载 ECDICT 的 `ecdict.csv`（MIT）；
2. 按内置标签抽取四个阶段词表：
   - 阶段一基础：`zk`（中考/小初核心）+ Oxford 3000 高频词；
   - 阶段二进阶：`gk`（高考 ≈ 高中 3500）；
   - 阶段三高手：`cet4`；
   - 阶段四大师：`ielts` + `toefl`；
3. 生成脚本（Node，开发期一次性工具）产出 `words/stage-N.json`：`{id, word, phonetic, meaning[], stage, chapter}`；章节粒度：阶段一 40 词/章，阶段二至四 100 词/章；
4. 语法题库：自编 JSON 题库（讲解卡片 + 选择题，每单元 8–12 题），随源码维护。

## 4. 架构

```
english-quest/                    # 工作目录内的项目根
├── index.html                    # 入口（构建后所有 JS/CSS 内联为单文件）
├── package.json / vite.config.ts # Vite + vite-plugin-singlefile
├── src/
│   ├── main.ts                   # 启动、路由、全局状态初始化
│   ├── views/                    # 视图：Home / Map / Typing / Grammar / Stats
│   ├── engine/
│   │   ├── typing.ts             # 打字引擎（逐字母判定、WPM、连击、计时）
│   │   ├── review.ts             # 间隔复习调度（集成 ts-fsrs）
│   │   ├── grammar.ts            # 语法题加载与判定
│   │   └── progress.ts           # 经验/等级/关卡解锁/星级
│   ├── store/
│   │   └── storage.ts            # localStorage 读写（带版本迁移）
│   ├── fx/                       # 粒子、彩带、音效（WebAudio 合成）
│   ├── data/                     # 词库 JSON、语法题库 JSON、成就定义
│   └── styles/                   # 卡通设计系统（CSS 变量、按钮/卡片组件类）
├── scripts/
│   └── build-words.mjs           # ECDICT → 分阶段分章词表生成器
└── dist/index.html               # 交付产物（单文件）
```

**原则**：无运行时依赖、无网络请求（纯离线可用）；类型安全（TS）；模块小而单一职责。仅有的第三方运行时依赖：**ts-fsrs**（MIT，复习调度）。

## 5. 数据模型（localStorage，键前缀 `eq:`）

```ts
eq:profile      = { xp, level, streak, lastCheckinDate, totalMinutes,
                    dailyGoal: { words, grammarUnits }, goalsMetToday: bool }
eq:stageProgress= { [levelId]: { [chapterId]: { state: 'locked'|'open'|'done',
                    stars: 0-3, bestAcc, bestWpm } } }
eq:wordStats    = { [wordId]: { correct, wrong, lastSeen,
                    fsrs: { due, stability, difficulty, state } } }  // ts-fsrs 卡片状态
eq:grammar      = { [unitId]: { done, score, answers: number[] } }
eq:mistakes     = { wordId, wrongAnswer, ts }[]          // 错题本
eq:achievements = { [achievementId]: { unlockedAt } }
eq:settings     = { sound, theme, showMeaning, dictationOnly }
```

版本字段 `eq:schemaVersion`，升级时提供迁移函数。

## 6. 游戏化系统（8 大机制）

1. **打字引擎**：逐字母实时着色（对绿/错红）、错误抖动、回车提交、Esc 跳过；WPM/正确率/计时实时刷新。**三阶递进模式**：跟打（显示单词照打）→ 默写（看释义/音标盲打，默认模式）→ 听写（听发音盲打，speechSynthesis 播报）。**错误重打**：打错需重打（防错误肌肉记忆）；同一词累计错 3 次显示答案并强制进入复习队列。
2. **连击**：≥3 连击徽章变色（黄→红）；5/10/20/50 连击触发里程碑（星星粒子 + 彩带 + 音效）；打错断连击（每日首次断连击不罚）。
3. **经验等级**：每词 +10 XP，连击加成 ×1.2（≥3）/ ×1.5（≥10）；等级阶梯（新手→学徒→…→大师），升级全屏庆祝。
4. **每日打卡**：完成每日目标（默认 30 词或 2 语法单元，完成任一即达标，可配置三档）自动打卡；🔥连续天数 + 月度热力图；断签用冻结卡（补签卡，每周自动 +1，上限 3）。
5. **闯关星级**：正确率 ≥60% 通关（1★）、≥80%（2★）、≥95%（3★）；3★ 解锁主题奖励；关卡按顺序解锁。
6. **成就徽章**：首次 10 连击 / 累计 1000 词 / 打卡 7·30·100 天 / 单阶段全 3★ 等 20+ 枚，成就墙展示。
7. **间隔复习**：集成 **ts-fsrs（MIT）** 调度错词/不熟词；每日任务 = 新词 + 到期复习词混合；复习量上限可调（防 burnout）。
8. **音效与主题**：WebAudio 合成全部音效（打字、正确、错误、升级、成就，零音频文件）；发音用浏览器 `speechSynthesis`（en-US）；通关阶段解锁新配色主题。

## 7. 四阶段路线

| 阶段 | 词汇（章节数 × 每章词数） | 语法 |
|---|---|---|
| 🟢 基础 | 小初核心 ~1200 词（30 章 × 40） | 10 单元：be 动词、名词复数、代词、一般现在时、疑问句、there be、形容词副词、冠词、祈使句、基础介词 |
| 🟡 进阶 | 高中 3500（35 章 × 100） | 时态全系（过去/将来/进行/完成）、被动语态、情态动词、比较级、从句入门（宾语/定语） |
| 🔵 高手 | 四级核心 ~2000 词（20 章 × 100） | 虚拟语气、非谓语、倒装、强调句、从句全系、主谓一致 |
| 🟣 大师 | 雅思/托福 ~3000 词（30 章 × 100） | 长难句解析、综合改错、书面语精讲 |

- 每章词汇关卡内，约 15% 题目为**词形变化题**（由 ECDICT exchange 字段自动生成：复数、过去式、三单、比较级），形成「单词训练」维度。
- 阶段末设「阶段测验」（词 20 题 + 语法 10 题，80% 通过进入下一阶段）。

## 8. UI/UX 设计语言

- **配色**：Duolingo 系（绿 #58CC02 / 黄 #FFC800 / 蓝 #1CB0F6 / 紫 #CE82FF / 红 #FF4B4B），浅米色背景。
- **组件**：厚底边按钮（按下有物理下沉感）、圆角卡片、大圆角气泡。
- **动画**：弹性缓动（cubic-bezier(.34,1.56,.64,1)）、卡片弹入、数字回弹、粒子/彩带。
- **字体**：系统字体栈 + 圆润字重，零外部字体依赖（离线可用）。
- **布局**：桌面优先（打字需要实体键盘），>=1200px 时内容居中 max-width 960px；移动端降级为「选择拼词」模式提示。

## 9. 非目标（明确不做）

- 不做后端/账号/多设备同步/排行榜服务器/社交分享
- 不接任何在线 API（离线可用为第一原则；speechSynthesis 是浏览器本地能力，不算在线依赖）
- 不复制 GPL/AGPL 项目的数据文件与代码；复用仅限 MIT/Apache/BSD
- 不做移动 App
- v1 不引入 Harper WASM 判分（语法为选择题）；「句子填空/改错」列为 v2 路线

## 11. 风险与对策

| 风险 | 对策 |
|---|---|
| ECDICT 数据量大、含生僻词/格式噪声 | 生成脚本做清洗（去重、剔除非字母词、长度过滤），人工抽检 |
| ts-fsrs 集成与卡片状态持久化 | 按官方 TS 示例接入；卡片状态随 wordStats 序列化，含版本迁移 |
| localStorage 容量（5MB） | 只存进度与统计，不存词库本体；词库随构建产物内联 |
| 双击 file:// 下模块加载 | 构建用 vite-plugin-singlefile 全内联，无模块边界问题 |
| speechSynthesis 语音质量因系统而异 | 提供音标展示兜底；音效与 TTS 独立开关 |

## 12. 验收标准

1. 双击 `dist/index.html`（或拖入浏览器）即可完整使用，无任何外部请求。
2. 打完整一章词，正确率/星级/XP/连击结算正确，数据刷新后仍在。
3. 三种模式可用：跟打、默写（默认）、听写；错误重打生效（错 3 次显示答案并入复习队列）。
4. 连续打卡跨天正确累计；冻结卡逻辑可用。
5. 语法单元：讲解→练习→判分→进度记录闭环。
6. 词形变化题（复数/过去式/三单）由词库自动生成并正常判分。
7. 复习队列按 ts-fsrs 调度在到期日重现。
8. 无 console 报错；100 词/分钟输入无卡顿（requestAnimationFrame 动画 + 事件委托）。
