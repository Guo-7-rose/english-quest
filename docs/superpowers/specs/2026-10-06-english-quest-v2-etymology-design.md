## 1. 改造目标

用户原话拆解 → 四条硬需求：

| # | 需求 | 落地方式 |
|---|---|---|
| 1 | **不要打字练习形式** | 删除打字引擎、WPM、连击、打错重打、打字视图及其测试 |
| 2 | **背单词用词源方式，拆成前缀/后缀记住** | 三层助记体系：真词源 → 构词拆解 → AI 助记；以**词根家族**为浏览单位 |
| 3 | **语法更详细 + 英语思维 + YouTube 视频课** | 语法单元重写为「英语思维讲解 + 规则 + 例句 + 常见错误 + 练习 + 关联视频」；视频页内播放 |
| 4 | **全部解锁，想学什么学什么；分板块；单词顺序：日常 → 初中 → 高中 → 四级** | 移除所有锁定与门禁；导航按板块划分；单词板块按此顺序排列 |

参考站点：[LetMeEnglish](https://letmeenglish.com/zh-hans/)（语法分类 + 词汇辨析 + 常用句型 + 日常表达，形式为「知识点文章 + 练习」）、[OpenEtymology](https://github.com/openetymology/OpenEtymology)（词源单词本组织形式，数据授权 CC BY-SA 且完整库未开源，**仅参考形式不采用数据**）。

## 3. 数据基础（全部经实测验证）

### 3.1 词源数据：ECDICT `wordroot.txt`（MIT）

实测（2026-10-06）：

- **611 个词根/前缀/后缀**：词根 423、前缀 110、后缀 78
- **9,276 个例词**，去重后 **6,716 个可拆解单词**
- 每条含：含义（英文）、来源语言、例词数组、近义/反义词源
- 来源语言分布：**拉丁 377 / 希腊 205 / 古英语 20**
- 家族规模：1-3 词 56 个、4-9 词 248 个、10-29 词 237 个、**30+ 词 70 个**

### 3.2 覆盖率实测与三层策略

| 词表 | 词数 | 词源库直出 | 加可信构词规则 | 剩余（AI 助记补齐） |
|---|---|---|---|---|
| 初中（zk） | 1,597 | 228（14.3%） | +51 | ~1,318 |
| 高中（gk） | 3,674 | 810（22.0%） | +168 | ~2,696 |
| 四级（cet4） | 3,837 | 1,102（28.7%） | +250 | ~2,485 |

**关键实测教训**：宽松规则拆解会产生**假词源**——`advice=ad+vice`、`afraid=af+raid`、`beach=be+ach`、`album=al+bum` 全部错误。因此：

- **[词源] 层**：只展示 ECDICT 词源库的**人工校订结果**（含来源语言），可信
- **[构词] 层**：仅当「前缀/后缀 + **完整常用单词**（ECDICT frq ≥ 2000）」时展示，如 `un+happy`、`teach+er`、`re+write`；界面明确标注「构词记忆」
- **[助记] 层**：其余词由 AI 生成场景联想/搭配/词族对比，界面标注「助记（非词源）」

三层在 UI 上用颜色标签区分，绝不混淆。

## 5. 页面与导航（全解锁）

```
🏠 学习面板   📚 单词板块   🌱 词根词缀库   📖 语法训练   🎬 视频课   🔁 复习   📊 数据   ⚙️ 设置
```

**无任何锁定**：所有词包、词根家族、语法单元、视频均可直接点击进入。

- **🏠 学习面板**：今日打卡🔥、连续天数、XP/等级、今日推荐（随机主题 + 词根家族 + 语法单元）、快捷入口、进度概览
- **📚 单词板块**：按顺序排列的板块卡片
  1. **日常词汇**：18 主题词包（家庭/食物/购物/交通/身体/时间/天气/居家/工作/情绪/动作/衣物/学校/运动/医疗/出行/性格/社交）+ **生活表达包**
  2. **初中词汇**（1,597 词）、3. **高中词汇**（3,674 词）、4. **四级词汇**（3,837 词）
  - 词表页：每词一行 = 单词 + 音标 + 释义 + **三层拆解标签** + 状态标记（✅记住 / 🔁待复习）；点词展开详情（拆解、来源语言、同族词、例句、标记按钮）
- **🌱 词根词缀库**（用户指定的核心玩法）：
  - 总览：611 家族网格，可按**类型**（词根/前缀/后缀）与**首字母**筛选，按「对本阶段词表贡献度」排序
  - 家族页：家族含义 + 来源语言 + 该家族**全部同族词**（每词带音标、释义、完整拆解）+ 近义/反义家族
  - 双向链接：词 → 其词根家族；家族词 → 词详情
- **📖 语法训练**：单元网格（无锁）→ 单元页：**英语思维讲解** → 规则表 → 例句（正/误对比）→ 常见错误 → 练习题 → 关联视频卡（页内播放）
- **🎬 视频课**：内置清单按主题分组（英语思维/时态/冠词/从句/非谓语/虚拟语气…）+ 页内 iframe 播放 + 每课配文字要点 + **「+ 添加我的视频」**（粘贴 YouTube 链接，自动 oEmbed 取标题，存 localStorage）
- **🔁 复习**：FSRS 队列（沿用 v1 引擎），题型为**选择题/回忆式**（不打字）
- **📊 数据**：沿用 v1（累计词数、热力图、成就墙、错题本）+ 新增「词根掌握度」
- **⚙️ 设置**：沿用 v1（音效/发音/释义开关、每日目标三档、主题解锁）→ 主题改为**全部解锁**（配合全解锁定位）

## 6. 学习流程（无打字）

1. **学**：进入词根家族页或主题词包 → 浏览三层拆解 + 释义 + 例句 + 同族词
2. **标**：每词点「✅ 记住了」或「🔁 需复习」→ 写入 wordStats
3. **测**：选择题自测四种题型 —— 看词选义 / 看义选词 / **选出正确拆解** / 选词根含义；答对 +XP
4. **复习**：FSRS 到期词进入复习队列，按 1/3/7/15 天节奏重现（ts-fsrs，沿用）

正反馈保留：XP/等级升级动画、成就徽章、打卡🔥、彩带/粒子、合成音效；**移除**：WPM、连击、打错重打。

## 7. 语法模块设计（详细化 + 英语思维）

每个语法单元的结构：

1. **英语思维开篇**（为什么英语这样说）：对比中文思维，如
   - 时态：中文靠「了/过/在/将」+ 时间词，英语把时间**强制编码进动词形态**
   - 冠词：中文没有冠词，英语**必须**回答「泛指还是特指」
   - 语序：英语靠**位置**表意（主谓宾固定），中文靠词序灵活 + 助词
2. **规则表**：结构公式化（如 `have/has + 过去分词`）
3. **例句**：正例 + 典型错例对照，配中文翻译与「错在哪」
4. **常见错误**：中国学习者高频错误清单
5. **练习**：5-10 题选择题（含解析）
6. **关联视频**：1-2 个已核验视频卡，页内播放

**M1 单元清单（12 个核心）**：英语句子骨架（五大句型）、be 动词与存在、名词与可数性、冠词、代词、一般现在时、进行时、过去时、完成时、将来表达、情态动词、介词
**M2 扩展**：被动语态、定语从句、宾语从句、状语从句、非谓语（不定式/动名词/分词）、虚拟语气、倒装与强调、主谓一致、时态综合、语篇连接、英语思维专题（信息结构与焦点）

## 11. 验收标准

1. 双击 `dist/index.html` 即可使用，无外部请求（视频播放除外，需联网）
2. **任何**词包/词根家族/语法单元/视频都能直接进入，无任何锁定提示
3. 单词板块顺序为 日常 → 初中 → 高中 → 四级
4. 每个有词源的词能看到**真实拆解 + 来源语言 + 同族词**；无词源的词显示构词或助记标签，三者视觉可区分
5. 词根家族页能展出该家族全部同族词，且词 ↔ 家族双向跳转正确
6. 语法单元包含英语思维讲解、规则、例句、常见错误、练习、关联视频六部分
7. 内置视频全部为 oEmbed 核验通过的真实视频；用户可自行粘贴链接添加
8. 自测答对 +XP、错题进 FSRS 复习队列；打卡/热力图/成就正常
9. `npm.cmd test` 全绿（打字相关测试已移除），`npx tsc --noEmit` 零错误，构建为单文件
